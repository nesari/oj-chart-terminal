# BUGFIX — ROUND 58 (v1.9.9)

**گزارش کاربر:** «من فقط یک سرور رو توی این لیست می‌بینم — اگر می‌شه تمام سرورها رو اضافه کن، اگر هم نمی‌شه بهم بگو.»
(پس از ارتقا به v1.9.8 / راند ۵۷ — اسکرین‌شات: پاپ‌آپ «Broker servers» با تنها یک سطر `CapitalxtendLLC-MU`)

## چرا راند ۵۷ روی ماشین کاربر شکست خورد

راند ۵۷ درخت سرورهای بروکر را از `config/servers.dat` ترمینال می‌خواند، ولی فرمت این فایل باینری و **بدون هیچ مستند عمومی** است. برداشت‌کنندهٔ آن راند فقط چیدمان‌های رشتهٔ **UTF-16LE** را اسکن می‌کرد (پیشوند طول u32 / u16 / خاتمه‌با-نال). یافته‌های تحقیق این راند:

- مستند رسمی متاتریدر: `servers.dat` = «تنظیمات سرورهای اتصال» در پوشهٔ داده؛ همان منبع دیالوگ سرور خود ترمینال.
- فروم mql5 (بیلد ۳۵۵۰): فایل «باینری» است؛ فرمت منتشر نشده. ابزار تجاری Dat2Srv (mtapi.io) اثبات می‌کند فایل **قابل parse آفلاین** است (نه رمز)، ولی فرمتش را منتشر نمی‌کند.
- دیتابیس‌های عمومی سرورهای بروکر (مثل TradeVPS) فقط ۳۷ بروکر دارند — Capitalxtend نیست؛ منبع جایگزین قابل اتکایی نیست.

نتیجه: اگر فایل واقعی کاربر رشته‌ها را با چیدمان **ANSI/ASCII** ذخیره کرده باشد (میراث MT4 — فایل‌های `srv`/`servers.dat` آن نسل رشته‌های طول-پیشوندی Pascal یا خاتمه‌با-نال ASCII دارند)، هر سه اسکن UTF-16 راند ۵۷ خالی برمی‌گردانند → گیت خود-اعتبارسنج (وجود نام سرور اکانت در هاروست) رد می‌کند → fallback تک‌سرور. دقیقاً همان تک‌سطری که کاربر دید.

## رفع — فقط `provider/mt5.py` (رندرر صفر تغییر)

1. **هاروست ۷ اسکنی:** سه چیدمان UTF-16 قبلی + چهار چیدمان ASCII/ANSI (طول-پیشوندی u32، طول-پیشوندی u8، خاتمه‌با-نال، تک‌بایتی). پرحاصل‌ترین انتخاب می‌شود؛ گیت خود-اعتبارسنج سر جای خودش مانده، پس اگر اسکن غلطی برنده شود نتیجه اینرت است (هرگز به UI نمی‌رسد).
2. **مسیرهای کاندید بیشتر:** علاوه بر `data_path` ترمینال و پوشهٔ نصب (ترمینال portable)، اکنون **glob** همهٔ ترمینال‌های نصب‌شده از `%APPDATA%/MetaQuotes/Terminal/*/config/servers.dat` هم امتحان می‌شود (تا ۱۲ کاندید، dedupe).
3. **پینگ DNS برای سرورهای بی‌آدرس:** اگر برای یک سرور هم‌بروکر آدرسی جفت نشده باشد، نام سرور مثل خود ترمینال از DNS حل و TCP-connect واقعی روی پورت ۴۴۳ اندازه‌گیری می‌شود؛ نام‌حل‌نشده = بدون پینگ (هرگز عدد ساختگی).
4. **دامپ تشخیصی بی‌صدا:** در صورت شکست گیت، فایل `%TEMP%\mt5_servers_dat_debug.txt` نوشته می‌شود: مسیرهای امتحان‌شده، رشته‌های هاروست‌شده، و hexdump ۱.۵ کیلوبایت ابتدای فایل واقعی کاربر — تا اگر باز هم چیدمان متفاوت بود، فرمت دقیق از روی واقعیت بازسازی شود نه حدس بعدی. این فایل هیچ اثری در UI ندارد.

## حفاظت‌های دست‌نخورده

- گیت خود-اعتبارسنج: هاروست فقط وقتی باور می‌شود که نام سرور اکانت در آن باشد؛ وگرنه fallback تک‌سرورِ راند ۵۵ — خرابی هرگز لاگین/چارت را نمی‌شکند.
