# FEATURE — ROUND 61 (v1.9.12) — منوی الگوها/الیوت/چرخه‌ها عین تریدینگ‌ویو

## درخواست کاربر

دو اسکرین‌شات مقایسه‌ای: اولی منوی ابزار تریدینگ‌ویو، دومی منوی فعلی اپ. خواسته‌ها:

1. منوی فعلی اپ برداشته شود و **دقیقاً همان مواردی که در منوی تریدینگ‌ویو هست** جایگزین شود.
2. آیکون هر آیتم هم **دقیقاً مثل نمونهٔ تریدینگ‌ویو** باشد.
3. ابتدا دربارهٔ هر ابزار تحقیق شود: برای چه کاری هست، چطور کار می‌کند، روی چارت چطور رسم می‌شود و چه تنظیماتی دارد؛ سپس در اپ پیاده‌سازی شود.
4. ترتیب چینش و دسته‌بندی **به همان صورتی که در تریدینگ‌ویو هست** باشد.
5. فقط همین کار؛ به بقیهٔ بخش‌های اپ دست نخورد؛ چیزی حذف نشود.

## آنچه در تریدینگ‌ویو هست (مرجع: اسکرین‌شات + صفحهٔ رسمی «Drawing tools available on TradingView»)

| بخش | ابزارها (به همان ترتیب) |
|---|---|
| CHART PATTERNS | XABCD pattern، Cypher pattern، Head and shoulders، ABCD pattern، Triangle pattern، Three drives pattern |
| ELLIOTT WAVES | Elliott impulse wave (1-2-3-4-5)، Elliott correction wave (A-B-C)، Elliott triangle wave (A-B-C-D-E)، Elliott double combo wave (W-X-Y)، Elliott triple combo wave (W-X-Y-Z) |
| CYCLES | Cyclic lines، Time cycles، Sine line |

## تحقیق سه ابزار CYCLES (جدید) و پیاده‌سازی

هر سه در `src/renderer/js/drawing/tools2.js` با همان قرارداد `TOOLS` (لنگرهای `{t,p}`، `draw/handles/hitBody/dragHandle`) پیاده شدند:

### Cyclic Lines — «خط‌های چرخه‌ای»
- **برای چه کاری**: رسم یک ردیف خط عمودی با فاصلهٔ زمانی برابر برای دیدن تناوب چرخه‌های بازار و نقاط عطف احتمالی بعدی.
- **چطور رسم می‌شود**: دو کلیک — لنگر اول سرِ خط اول، لنگر دوم سرِ خط دوم؛ فاصلهٔ آن‌ها = طول دوره؛ سپس خط‌های عمودی تمام‌قد با همان فاصله تکرار می‌شوند.
- **تنظیمات (تب Style، آینهٔ TV)**: Line (رنگ/ضخامت/نوع)، `Coeff` (ضریب طول دوره: 0.25…5)، `Cycles` (تعداد خط، پیش‌فرض ۱۲)، `Extend left` / `Extend right` (تکرار به گذشته/آینده).

### Time Cycles — «چرخه‌های زمانی»
- **برای چه کاری**: مشخص‌کردن یک چرخهٔ زمانی کامل (شروع/میانه/پایان) و تکرار آن به‌سمت آینده برای پیش‌بینی چرخهٔ بعدی.
- **چطور رسم می‌شود**: سه کلیک — خط مرزی روی لنگر اول، خط میانی روی لنگر دوم، خط مرزی روی لنگر سوم؛ کل دوره (مرز+میانی+مرز) با فاصلهٔ (tC−tA) تکرار می‌شود.
- **تنظیمات**: Line، `Cycles` (تعداد تکرار، پیش‌فرض ۵).

### Sine Line — «خط سینوسی»
- **برای چه کاری**: سوارکردن یک موج سینوسی روی چارت برای تحلیل چرخه‌ای — تطبیق چرخه‌های قیمت با یک موج سینوسی مرجع.
- **چطور رسم می‌شود**: دو کلیک — موج از لنگر A شروع می‌شود، روی خط روند A→B سوار است؛ لنگر B طول یک دورهٔ کامل در زمان و دامنه را از اختلاف قیمت دو لنگر می‌گیرد؛ موج به دو سمت تکرار می‌شود.
- **تنظیمات**: Line، `Coeff` (تعداد دوره در بازهٔ A→B: 0.5…3)، `Extend` (هیچ/چپ/راست/هر دو — پیش‌فرض هر دو)، `Trend line` (نمایش/عدم‌نمایش خط روند زیرین).

## تغییرات منو (`drawing/ui.js`)

- ساختار قبلی `GANN / ELLIOTT / PATTERN` (۱۵ ابزار) → ساختار دقیق TV: `CHART PATTERNS (6) / ELLIOTT WAVES (5) / CYCLES (3)` = ۱۴ ابزار با همان ترتیب بالا.
- نام نمایشی ۱۱ ابزار الگو/الیوت به **متن دقیق منوی تریدینگ‌ویو** تغییر کرد (tool id ها، موتور رسم، قالب‌ها و محبوب‌ها دست‌نخورده — مثلاً `elliott_i` همان است، فقط اسمش «Elliott impulse wave (1-2-3-4-5)» شد).
- **هیچ‌چیز حذف نشد**: چهار ابزار گان از راند ۶۰ در بخش GANN فاینای fibs در دسترس‌اند (tool id مشترک)؛ پیچ‌فورک‌ها هم همان‌جا و در فاینای lines.
- آیکون دکمهٔ نوار ابزار → زیگزاگ موج‌دار `patwaves` (شبیه دکمهٔ همان منو در تریدینگ‌ویو) + fallback جدید `GROUP_TITLE` برای tooltip دکمه‌هایی که base شان tool نیست: «Chart patterns, Elliott waves & cycles».

## آیکون‌ها (`ui/icons.js`)

`cycliclines` (ردیف خط عمودی)، `timecycles` (مرز+میانی+مرز)، `sineline` (موج سینوسی با دو لنگر)، `patwaves` (زیگزاگ TV). همگی stroke-based با همان سبک مجموعهٔ آیکون‌های موجود.
