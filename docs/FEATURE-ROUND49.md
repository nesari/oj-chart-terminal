# FEATURE — راند ۴۹ (v1.9.0): هایلایت نوار قیمت/زمان در هر سه حالت موس + منوی (+) تریدینگ‌ویو

## درخواست کاربر (با عکس تریدینگ‌ویو)

**مشترک بین هر سه حالت موس (Cross / Arrow / Dot):**
1. هایلایت موس روی نوار قیمت و نوار زمان باید در هر سه حالت وجود داشته باشد.
2. دکمه (+) قفل‌شده کنار هایلایتِ قیمت (مطابق عکس) — با کلیک، چند گزینهٔ عکس باز شود و «حتماً کار کنند» — در دارک و لایت تست شود.

**تفاوت‌ها (مثل TV):** فقط Cross خط‌چین زنده روی چارت دارد؛ Arrow بدون خط‌چین با موس عادی؛ Dot مثل Arrow با موس دایرهٔ توخالی (از قبل درست بود).

### رفتار در هر سه حالت

- **Cross:** خط‌چین + برچسب بومی قیمت + پیل زمان + (+) — همه مثل قبل، فقط (+) اضافه شد.
- **Arrow/Dot:** بدون هیچ خطی؛ پیل قیمت `.pax-live` + پیل زمان + (+) زنده با موس.
- در حالت Cross پیل DOM مخفی است تا برچسب بومی دوتایی نشود؛ هنگام فریز (منوی باز) پیل DOM روی همان نقطه می‌نشیند.
- کلیک (+) قیمت را تا بستن منو قفل می‌کند؛ حرکت موس یا خروج از پن آن را نمی‌شکند.

### پنج اکشن منو (همه واقعاً کار می‌کنند)

1. **Add alert on \<sym\> at \<P\>** → دیالوگ Create Alert موجود، با قیمت prefill.
2. **Buy 1 \<sym\> @ \<P\> limit** → تیکت سفارش (ثبت: خط‌چین سبز + toast).
3. **Sell 1 \<sym\> @ \<P\> stop** → تیکت سفارش (ثبت: خط‌چین قرمز + toast).
4. **Add order on \<sym\> at \<P\>…** → تیکت با Side/Type قابل انتخاب.
5. **Draw horizontal line at \<P\>** → خط افقی واقعی از فروشگاه drawings + undo + toast.

(ترمینال دمو است — بروکر واقعی ندارد؛ «کار کردن» سفارش = ثبت دیداری روی چارت + toast، بدون ادعای ارسال به بروکر.)
