# BUGFIX — راند ۴۶: جداکننده‌های قاب (Frame Separators) مثل تریدینگ‌ویو

- **نسخه:** 1.8.6 → **1.8.7**

- **فایل تغییرکرده در `src/`:** فقط `src/renderer/css/app.css` (+۱۶ خط، بدون حذف یا تغییر هیچ خط موجود)

## ۱) درخواست کاربر

> «تریدینگ‌ویو با یک Separator نوارها را از چارت و از همدیگه جدا کرده؛ یک مرزی با این جداکننده‌ها به‌وجود آورده. این را برای من هم اجرا کن — توی عکس با مستطیل‌های قرمز مشخص کردم.»

مستطیل‌های قرمز روی اسکرین‌شات تریدینگ‌ویو سه مرز را نشان می‌دادند: لبهٔ پایین نوار بالا، لبهٔ راست ریل ابزار چپ، و لبهٔ چپ ریل/پنل راست.

## ۲) ریشه‌یابی (eyedrop از خود اسکرین‌شات مرجع)

پیکسل‌های اسکرین‌شات تریدینگ‌ویو کاربر اسکن شد:

| ناحیه | مقدار اندازه‌گیری‌شده |
|---|---|
| خط جداکنندهٔ ریل چپ (ستون x59-62 در ۴ ردیف مختلف) | `#2e2e2e` — باند ~۲px CSS |
| خط جداکنندهٔ ریل راست (ستون x1878-1881) | `#2e2e2e` — همان باند |
| خط زیر نوار بالا (لبهٔ پایینی، بیرون از مستطیل قرمز) | `#2e2e2e` — همان باند |
| پس‌زمینهٔ ریل چپ / ریل راست / نوار بالا | `#0f0f0f` |
| بوردر ریل در حالت جمع (اپ) | `0` (قاعدهٔ `#left-toolbar.collapsed`) |

**نتیجه:** رنگ خط جداکنندهٔ TV دقیقاً `#2e2e2e` است — همان `--border` دارک اپ ما از راند ۴۵. تفاوت واقعی **پهنای خط** بود: TV باند ~۲ پیکسلی می‌کشد که کنار هر دو سطح همسایه دیده می‌شود؛ اپ ما ۱px داشت که کنار ریل روشن‌تر (`#1a1a1a`) عملاً محو می‌شد. (برای مرجع: کنتراست خط نسبت به ریل در TV برابر Δ31 است؛ در اپ Δ14.)

## ۳) تغییر اعمال‌شده

یک بلاک دارک‌اسکوپ به `app.css` اضافه شد که فقط **پهنای** پنج خط مرزی قاب را در تم تیره به ۲px می‌رساند (رنگ و استایل از قواعد پایهٔ موجود می‌آید و همان `var(--border)` است):

```css
body:not(.theme-light) #top-toolbar  { border-bottom-width: 2px; }
body:not(.theme-light) #left-toolbar:not(.collapsed) { border-right-width: 2px; }
body:not(.theme-light) #bottom-toolbar { border-top-width: 2px; }
body:not(.theme-light) #right-content { border-left-width: 2px; }
body:not(.theme-light) #right-tabs    { border-left-width: 2px; }
```

نکات ظرافتی:

- **`:not(.collapsed)`** لازم است چون `#left-toolbar.collapsed { border-right: 0 }` از نظر specificity هم‌تراز بلاک جدید است؛ بدون این محافظ، ریلِ جمع‌شده یک خط ۲px می‌گرفت.
- **اسکوپ دارک** تم روشن را پیکسل‌به‌پیکسل حفظ می‌کند (خط‌های مویی ۱px با `--border: #d5d9e2` مثل قبل).
- `box-sizing: border-box` سراسری است؛ پس ارتفاع/عرض نوارها (42/36/46/290/40px) ذره‌ای تغییر نمی‌کند و فقط ۱px از سطح داخلی هر نوار به خط اختصاص می‌یابد.
- چون هیچ‌کدام از پنج المان با `display:none` مخفی نمی‌شوند بجز از مسیر کلاس‌های موجود (`hidden`/`collapsed`)، هیچ حالت جدیدی خط اضافه نشان نمی‌دهد.

## ۴) عمداً دست نخورد

- جداکننده‌های داخلی خودِ نوارها (`.tb-sep`, `.lt-sep`, `.rp-sep`) — TV این‌ها را ۱px نگه می‌دارد.
- خطوط محور قیمت/زمان و جداکنندهٔ زیرپن‌ها (رسم بوم، `--pane-sep`) — در اسکرین‌شات علامت‌گذاری نشده بودند.
- پس‌زمینه‌ها و همهٔ رنگ‌ها (حاصل راندهای ۴۴/۴۵)، تم روشن به‌طور کامل، رفتارها و چیدمان.

## ۵) تست

`scripts/verify_round46.py`:

1. بوت تازهٔ دارک: عرض computed هر پنج مرز = `2px`، رنگ `rgb(46, 46, 46)`.
2. جمع‌کردن ریل چپ (`collapsed`): بوردر راست = `0px`؛ بازگرداندن: دوباره `2px`.
3. سوییچ به تم روشن: هر پنج مرز = `1px` با `rgb(213, 217, 226)` (`#d5d9e2` قبلی) — بی‌تغییری کامل.
4. اسکرین‌شات تمام‌صفحهٔ دارک + کراپ از سه مرز علامت‌گذاری‌شده در درخواست کاربر.
5. ممیزی ایستای diff: فقط ۱۶ خط افزوده در `app.css`.
6. صفر خطای کنسول صفحه.

رگرسیون‌ها روی همین درخت: `verify_round45` (۱۸/۱۸)، `verify_round44` (۱۵/۱۵)، `verify_round43` (۸/۸)، `verify_round42` (۱۳/۱۳)، `test_round40` (۱۴/۱۴)، `test_round38` (۲۸/۲۸).
