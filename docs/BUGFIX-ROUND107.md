## گزارش کاربر (با عکس)

«این دو تا عکس رو ببین برات علامت زدم. موس رو بردم روی خط چین استاپ و تی‌پی — هیچ تگی نشون داده نمیشه.»

دو عکس: نشانگر به شکل ↕ (ns-resize) **دقیقاً روی خط‌چین SL (قرمز) و TP (سبز)** پارک شده، کراس‌هیر عمودی هم همان‌جاست، ولی هیچ جعبه‌ای در هیچ نقطهٔ تصویر نیست.

نکتهٔ تشخیصی حیاتی: ↕ یعنی `_cursorSync` اجرا شده و `_hit` خط را پیدا کرده — پس **hit-test و هندسه سالم‌اند**. درگ کاربر هم (راند ۱۰۵) سالم بود. شکاف باید بعد از hit-test و مخصوص مسیر «نمایش تگ» باشد.

## اثبات با repro واقعی (نه حدس)

اپ با بروکر دمو در کرومیوم headless بوت شد؛ یک پوزیشن واقعی EURUSD با SL/TP باز شد؛ ماوس با Playwright دقیقاً روی مختصات صفحه‌ایِ خط SL پارک شد؛ همهٔ حلقه‌های زنجیره probe شدند:

```
probe:  _onHover ×12   _showTip ×4   hit ×26   errs []
state:  cursorOverlay=ns-resize   tipDisplay=''   tipKey='sl#500002'
        tipHtml = 'SL 1.08360 · EURUSD #500002 / -$6.00 / 60 points · 6 pips / …'
        tipRect = {x:0, y:0, w:0, h:0}   ← تگ «نمایش داده شده» ولی صفر در صفر!
```

یعنی: زنجیره کامل شلیک می‌کند، HTML همراه ردیف دلاری ساخته می‌شود، inline style هم `''` است — و با این حال جعبه **نامرئی** است.

## ریشه (Root Cause)

نمایش تگ با این خط انجام می‌شد:

```js
tip.style.display = html ? '' : 'none';
```

`''` فقط **inline style را پاک می‌کند**. اما کلاس تگ از راند ۱۰۰ چنین پیش‌فرضی دارد:

```css
.trade-hover-tip { position: fixed; … ; display: none; }
```

پس بعد از پاک‌شدن inline، قانون کلاس دوباره حاکم می‌شود و **computed display همیشه `none` می‌ماند**. تگ از روز اولِ تولدش «در یک المان مخفی» رندر می‌شد — همهٔ راندها.

**چرا درگ همیشه کار می‌کرد؟** چیپ درگ با `''` toggle می‌شود، ولی کلاس `.trade-drag-chip` در CSS هیچ `display:none` ندارد (مخفی‌سازی اولیهٔ آن inline است). پس `''` برای چیپ قانونی است و چیپ نمایان می‌شود. دقیقاً همان شکاف دوگانه‌ای که کاربر بارها گزارش کرد: «درگ اوکی، هاور نه».

## رفع

### ۱. overlay.js — نمایش با مقدار برندهٔ صریح

```js
tip.style.display = html ? 'block' : 'none';
```

inline `block` بر قانون کلاس می‌چربد (specificity inline > class، بدون نیاز به `!important`). مخفی‌سازی‌ها همه با `'none'` هستند و سر جایشان می‌مانند. شاخهٔ «لغزش روی خط» (`tip.style.display !== 'none'`) و گارد repaint بعد از رسیدن spec هم با همین قرارداد سازگارند.

### ۲. history.js — همان دام، همان فیکس

جعبهٔ هاورِ معاملات بسته‌شده (`.th-hist-tip`) هم `display:none` در کلاس داشت و هم toggle با `''`:

```js
tip.style.display = 'block';
```

یعنی جعبهٔ «سود/زمان معاملهٔ بسته‌شده» که از راند ۱۰۰ قرار بود بالای خط ورود→خروج نمایش داده شود، عملاً هرگز دیده نشده بود — این راند رایگان تعمیر شد.

## تست

`node scripts/test_round107_tip_visible.mjs` → ۲۳/۲۳:

- **A (آینهٔ cascade):** مدل `computed = inline !== '' ? inline : cssDefault` — بازتولید باگ قدیمی (`''` + `none` کلاس → نامرئی) و اثبات فیکس (`'block'` → نمایان) برای هر دو کلاس تگ
- **B (قرارداد سورس):** `_showTip` فقط با `'block'` نمایش می‌دهد؛ هیچ مسیر نمایشی با `''` باقی نمانده؛ hide ها با `'none'`؛ کلاس‌های CSS همان `display:none` پیش‌فرض را دارند (دام مستند شده، نه حذف)
- **C (نشانگر چیپ درگ):** `.trade-drag-chip` باید بدون `display:none` بماند چون toggle آن `''` است — اگر کسی روزی به کلاسش display:none اضافه کند، تست C1 می‌شکند
- **D (ماشین حالت):** show → visible؛ leave → hidden؛ re-hover → دوباره visible (بدون dead-state)؛ slide → visible با محتوای تازه؛ html خالی → مخفی (بدون جعبهٔ خالی شناور)
- **E (محتوا):** ردیف پول از `_lineMoney`، نماد در تیتر SL/TP و قرارداد نمایش لحظه‌ای (نبودن `TIP_DELAY`/`TIP_TTL` به‌عنوان کد) پین مانده‌اند
