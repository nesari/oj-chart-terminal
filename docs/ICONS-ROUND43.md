# ICONS ROUND 43 — جایگزینی ۲۱ آیکون ابزار رسم با طرح تریدینگ‌ویو

## درخواست کاربر

کاربر ۷ اسکرین‌شات مرجع از پنل‌های تریدینگ‌ویو فرستاد (نوار ابزار رسم، منوی Cross/Dot/Arrow، LINES، FIBONACCI/GANN، CHART PATTERNS/ELLIOTT WAVES، FORECASTING) و خواست «فقط همین‌ها ساخته و جای‌گذاری شوند» بدون هیچ تغییر دیگری در نرم‌افزار.

## محدوده تغییر — فقط `src/renderer/js/ui/icons.js`

آیکون‌های اپ تصویر فایل نیستند؛ تعریف‌های SVG برداری درون رجیستری `I` هستند (استایل خطی، `currentColor`، بوم ۲۴×۲۴). با اسکریپت (`scripts/apply_icons_round43.py` در مخزن تحویل) دقیقاً ۲۱ خط از رجیستری جایگزین شد — هر خط، یک آیکون:

| گروه | کلیدها |
|---|---|
| مکان‌نما | `cross` (۴ تیک جدا با گپ مرکزی، بدون نقطه مرکز — TV) |
| خطوط | `hray` (نقطه فقط در سر لنگر)، `parallel` (۲ خط جدا + ۳ نقطه)، `regression` (باند مورب + ۳ نقطه)، `infoline` (نقطه + جعبه برچسب) |
| فیبوناچی | `fib` (+ نقطه سر/ته مورب)، `fibext` (زیگزاگ ۴ نقطه + سطوح توپر)، `fibchannel` (۳ مورب موازی)، `fibcircles` (۲ حلقه + نقطه مرکز/لبه) |
| گن | `gannbox` (شبکه یک‌سوم + قطر ↗ + نقطه)، `gannsquare` (شبکه + ضربدر + نقطه) |
| الگوها | `xabcd`، `abcd`، `cypher`، `threedrives`، `elliott` (نقطه روی همه نقاط لنگر)، `trianglepat` (نقطه رئوس)، `hs` (شانه-سر-شانه + ۳ نقطه) |
| پیش‌بینی | `positionl` / `positions` (۳ خط هدف/ورود/استاپ + جعبه L/S) |
| ابزار | `measure` (خط‌کش مورب درجه‌بندی‌شده) |

آیکون‌هایی که از قبل با مرجع یکسان بودند (`trend`، `ray`، `extended`، `hline`، `vline`، `crossline`، `dot`، `arrowcur`، `trash`، `star`، `text`، `rect`، `magnet`، `lock/unlock`، `eye/eyeoff`، `zoomin` و…) عمداً دست نخوردند. آیکون‌های اسکرین‌شات‌ها که معادل در اپ ندارند (Sticker/اسلایدر تنظیمات، Trend Angle، Fib Spiral/Wedge، Flat Top/Bottom، Disjoint Channel، Ghost Feed، Sector و…) ساخته نشدند.

## تضمین «هیچ چیز دیگری تغییر نکند»

- شمارش کلیدهای رجیستری قبل/بعد: ۱۲۹ = ۱۲۹ (هیچ کلیدی اضافه/حذف نشد؛ `diff` مجموعه کلیدها خالی).
- هر جایگزینی «یک خط کامل» بود؛ `diff` نهایی فایل دقیقاً ۲۱ خط قدیم + ۲۱ خط جدید.
- `node --check` روی فایل نهایی سبز.
- رنگ، ضخامت خط، اندازه نمایش و رفتار کلیک از قبل توسط CSS/`currentColor` کنترل می‌شود — هیچ HTML/CSS/منطقی تغییر نکرد.
